## 주요 디자인 결정사항

### 레이아웃
- 콘텐츠 폭: `--content-w: 860px` (CSS 변수로 일괄 관리)
- 컨테이너: `max-width: 1100px`
- 섹션 패딩: `64px 0`
- 섹션 구분선: `::before` 가상요소로 콘텐츠 폭(860px)에 맞게 제한

### 会社概要 + 事業内容
- 동일 섹션(`#about`) 안에 세로로 배치
- 会社概要: 3문단 텍스트
- 事業内容: 별도 `services-block` (경계선 + eyebrow + 타이틀 + 4항목)
- 각 항목 앞에 오렌지 원형 마커(`::before`) 표시

### 会社情報
- `<table>` → `<dl>` 리스트로 변경
- 라벨: 소문자 uppercase `.72rem`, 값: `.9rem weight:300`
- 항목 간 구분선 없음

### アクセス
- 주소·전화·교통정보(위) + 지도(아래) 세로 배치
- 교통정보 앞 오렌지 원형 마커
- 지도: 860px 폭, 320px 높이

### 풋터
- 한 줄: 로고 · COMPANY / SERVICES / CONTACT · 카피라이트
- 배경: `var(--dark)` 다크브라운

## 트렌드 기법 적용

| 기법 | 구현 |
|------|------|
| Scroll reveal | `IntersectionObserver` → `[data-animate]` + `.in-view` |
| Staggered entrance | `data-delay="1~4"` → `transition-delay` |
| Hero phrase animation | CSS `@keyframes phraseIn` (0.25초 간격 순차) |
| Section rule reveal | `scaleX(0→1)` 애니메이션 |
| Eyebrow line accent | `::before` 20px 오렌지 선 |
| Frosted header | `backdrop-filter: blur(10px)` |
